Expense Tracker — C#

A simple console-based expense tracker built with C#.

Features

- Add income transactions
- Add expense transactions
- View all transactions
- Calculate total income, expenses, and balance
- View transaction statistics
- Delete transactions
- Validate user input

Technologies

- C#
- .NET
- Lists and methods
- LINQ

How to Run

1. Open the project in a C# environment.
2. Run "Program.cs".
3. Follow the menu instructions in the console.
